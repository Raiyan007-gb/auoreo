# Design documents

Approved design specifications for AUOREO, produced with the Elephant-Goldfish Model
(the `egm` Claude Code plugin: `/egm:egm-brainstorm` → `/egm:egm-draft` → `/egm:egm-review`
→ `/egm:egm-resolve`). Working files (`concepts_brief.md`, `design_draft.md`, review
reports) live in `.artifacts/egm/`, which is git-ignored; a design moves here once it is
reviewed and approved. `/egm:egm-drift-report docs/designs` compares these documents with
the code.
