# auoreo web UI

React 19 + Vite 8 SPA for the auoreo server. Everything talks to one origin: REST under
`/api`, the durable SSE stream at `/api/events`, and the WebSocket control plane at `/ws`.

| Path | What lives there |
|---|---|
| `app/` | The SPA (`app/src/pages`, `components`, `hooks`, `lib`), `vite.config.ts`, `tsconfig.json` |
| `sdk/openapi.json` | The committed API contract (generated by the backend, see below) |
| `sdk/types.gen.ts` | TypeScript types generated from `openapi.json` — never edit by hand |
| `sdk/client.ts` | Typed REST client + SSE subscription (types from `types.gen.ts`) |
| `sdk/control.ts` | WebSocket control-plane client (frames mirror `src/auoreo/schema/ws.py`) |
| `sdk/events.ts` | Event `data` payload shapes (SSE/WS events are not in OpenAPI) |
| `e2e/` | Playwright specs, config and the `run.mjs` launcher |

## Develop

```bash
npm ci
# terminal 1 — a keyless backend on the default port 4096
AUOREO_HOME=$(mktemp -d) AUOREO_GATEWAY=fake uv run auoreo serve
# terminal 2 — Vite dev server with HMR; proxies /api and /ws to the backend
npm run dev
```

The proxy target defaults to `http://127.0.0.1:4096`; point it elsewhere with
`AUOREO_URL=http://127.0.0.1:5000 npm run dev`. If the server has a password, paste the
token in **Settings** (stored in `localStorage`). A non-empty
`<meta name="auoreo-token">` in the served `index.html` takes precedence (the server does
not fill it in today).

## Build

```bash
npm run build      # typecheck + vite build → web/dist
```

`auoreo serve` serves `web/dist` at `/` (mounted after the API routers, with an SPA
fallback so deep links like `/session/<id>` load `index.html`). Assets are built with
absolute `/assets/…` URLs for that reason. The markdown renderer (`react-markdown`,
`remark-gfm`, `rehype-sanitize`) is a lazily loaded chunk.

## Generate API types

After any backend API change:

```bash
uv run python scripts/check_openapi.py   # from the repo root: rewrites web/sdk/openapi.json
npm run gen:types                         # openapi.json → sdk/types.gen.ts
git diff --exit-code -- sdk/types.gen.ts  # CI drift guard
```

Use the generated types (`components["schemas"][…]`, re-exported from `sdk/client.ts`)
for every REST call. Only event payloads, which OpenAPI cannot describe, live in
`sdk/events.ts`.

## Checks and e2e

```bash
npm run typecheck && npm run lint && npm run build
npm run e2e
```

`npm run e2e` boots a throwaway backend (`AUOREO_GATEWAY=fake uv run auoreo serve --port 0`
with a fresh `AUOREO_HOME`), runs Playwright against the built `web/dist` it serves, and
stops it. Build first. To reuse a running server instead, set `BASE_URL`:

```bash
BASE_URL=http://127.0.0.1:4096 npm run e2e -- ops.spec.ts
```

Playwright uses the pre-installed Chromium (see `e2e/playwright.config.ts`); do not run
`playwright install`. Screenshots are written to `<repo>/.artifacts/ui/` (gitignored).

The fake gateway echoes messages back. `/tool read {"path":"README.md"}` makes the agent call
a tool, and `/tool bash {"command":"echo hi"}` needs approval, which is a handy way to test
the approval flow by hand.
